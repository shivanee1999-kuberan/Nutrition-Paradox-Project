# Nutrition Paradox Project

## Overview
This project analyzes global obesity and malnutrition data using Python and SQL.

## Features
- Data extraction using WHO API
- Data cleaning and preprocessing
- Feature engineering
- SQL database storage
- Exploratory Data Analysis (EDA)
- Data visualization

## Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- SQL (MySQL)
- API Integration

## Project Workflow
1. Collected data from WHO API
2. Cleaned and transformed the dataset
3. Created new features (age group, obesity level, etc.)
4. Stored data into SQL database
5. Performed analysis using SQL queries
6. Created visualizations for insights

## Key Insights
- Compared obesity and malnutrition trends globally
- Identified high-risk regions and countries
- Analyzed differences based on age group and gender
